# Desenvolvimento Web com NET

Snapshot tecnico independente para validar CI e staging temporario. O codigo funcional existente foi preservado. Relatorios academicos, identificacao do aluno e evidencias pessoais permanecem fora deste repositorio.

O workflow inclui restore, build, runner de integracao .NET, npm ci, testes de contrato, build React, publish, build de duas imagens rastreaveis, smoke tests e rollback com verificacao do digest.

Staging HTTPS externo exige autorizacao e e temporario. Nenhuma assinatura ou recurso pago e criado. O repositorio PortalTarefas existente nao e utilizado por este projeto.
